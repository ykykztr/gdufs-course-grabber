# 广外抢课助手（接口版）

> 针对广外教务（强智新版模板 `/jsxsd/xsxk/`）的选课辅助用户脚本。
> 个人使用；教务接口会随学校系统变化，不保证任何一轮可用。

## 它解决什么问题

广外的选课页有几个绕不开的麻烦：

- **轮次不放出来就看不到**，要人一直守着刷新
- **课程列表要等到开放那一刻才一起出现**，等你点进去、页面加载完、读完类别表，名额往往已经没了
- **一门课的多个教学班名字一样**（比如 19 个分组全叫「体育（3）」），页面上分不清要点哪个
- **页面列表有时干脆不显示**，你没法判断是"没课"还是"你没资格"

这个脚本用**接口直连**解决前三个，并且因为完全不依赖页面渲染，第四个也不影响使用。

## 功能

- 🛰 **守候轮次**：轮次还没放出来时自动替你重查（并点页面「查询」），一出现就自动进入
- 🎯 **进入守候**：进轮次后挂着，课程列表一到开放时刻出现就抢（不用守着电脑到点）
- ⚡ **T0 高频**：开放前后一段时间内把刷新压到 350ms
- **统一队列**：通识类别 / 必修分组 / 关键词三类任务进同一个队列，**同时盯、逐个抢**
- **通识 + 必修两条链路**：必修按**分组名**匹配（课名是聚合名，不能用）
- **抢到自动停**，被服务端拒绝（不开放 / 已选其它班）也会立刻停并说明原因

## 安装

1. 浏览器装 **Tampermonkey**（篡改猴）
2. 安装 `gdufs-grabber.user.js`（下载后拖进浏览器，或装好后手动导入）
3. **装完按 F5** —— 不按的话页面里跑的还是旧代码

## 快速开始

```
等待页（选课轮次列表） → 面板点「🛰 守候轮次（自动刷新）」 → 走人
```

脚本会在轮次出现时自动进入、在课程出现时自动抢、抢到后自动停。

## 控制台命令

按 F12 打开控制台，输入（`GRAB` 是脚本挂的全局对象）：

| 命令 | 作用 |
|---|---|
| `GRAB.version` | 当前版本号（先验它，确认新版真的生效） |
| `GRAB.alive()` / `GRAB.alive(30)` | 心跳 / 在跑多久 / 两个池子最后刷新时间 / 报错 |
| `GRAB.inspect()` | 队列内容 + 通识池与必修池的真相 |
| `GRAB.xhr()` | 挂上网络钩子并全量打印请求（查"某个按钮发了什么"） |
| `GRAB.testSubmit()` | 用假 id 打真接口，验证提交管道（**不会真选上**） |
| `GRAB.watch()` | 每 60 秒发一次请求，用来测会话超时 |
| `GRAB.addCat("人文科学")` | 入队一个通识类别任务 |
| `GRAB.addGroup("篮球")` | 入队一个必修分组任务 |
| `GRAB.tasks()` | 看队列全貌（类型 / 值 / 状态） |

**注意**：探针要在脚本跑起来之后用；刚 F5 就跑，看到的一定是空态。

## 已知限制（先读，能省很多困惑）

- **池子大小随"这一轮开放的课程范围"变**：某一轮只放网课，全库就只有 10 门；放全部课程时是 150 门左右。
  先看日志里的「每类别报数」——分布均匀说明服务端就是这些，不是漏刷。
- **换班要先退课**：同一门课已选其它教学班时，服务端会拒绝，必须先退掉已选的那个。
- **列表接口不查轮次、提交接口查轮次**：轮次关闭后会「抓得到但选不上」，报错是「公共选修选课不开放！」。
- **会话会被踢**：守候不要挂太久（实测双开页面会互相影响，单开一页测更准）。
- **只针对广外强智新版模板**：其他学校/其他模板需要自行调整接口与字段。

## 排错

| 现象 | 先看什么 |
|---|---|
| 改了版本没变化 | 有没有 **F5** |
| 面板没有轮次区块 | 当前页是选课页（正常不显示）；等待页才显示 |
| 池子是 0 门 | 日志的「每类别报数」；再看 `GRAB.alive()` 的刷新时间 |
| 匹配到但不提交 | 那行「匹配到 N 个班，但都不可抢：…」——满/冲突/已在课表 |
| 突然停止 | 「已停止 ← 函数名() 第 N 行」，它会点名是谁停的 |
| 搜索没结果 | 先确认模式：必修按**分组名**找，不按课程名 |

## 设计取舍

- **接口直连，不驱动页面**：教务的列表与提交都是同源请求，服务端认的是会话里的轮次上下文。
  实测过极端情况——**选课页整页没渲染出列表，脚本照样抢到**，所以不必依赖页面。
- **并行盯盘、串行提交**：数据源是全量的，盯 N 个目标不增加请求；每轮只提交一个，避免同时提交打架。
- **判据现场取真值**：不用"有没有某个元素"之类的代理指标判断状态（这类判断在页面重绘时会落空）。
- **空状态不静默**：没找到、不可抢、被拒绝，都会说明原因——静默会让人误以为功能坏了。
