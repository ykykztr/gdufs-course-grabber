# 广外抢课助手（接口版）

针对广外教务（强智新版模板）的选课辅助用户脚本。
它直接调教务接口抢课、不依赖页面 —— **页面不显示课程列表也能抢**。

## 装

1. 浏览器装 [Tampermonkey](https://www.tampermonkey.net/)（篡改猴）
2. 点这里安装 → [gdufs-grabber.user.js](https://github.com/ykykztr/gdufs-course-grabber/releases/latest/download/gdufs-grabber.user.js)
3. **装完按 F5**。在控制台（F12）输入 `GRAB.version`，能看到版本号就说明生效了

## 用

**第一步 · 等轮次**

打开选课轮次列表页，面板点「🛰 守候轮次（自动刷新）」。
它会每 3 秒替你重查一次，轮次一出现就自动进去。

**第二步 · 设目标**（下面三种可以混着设，都会各自盯着）

- **整类抢**：点亮类别芯片（比如「人文科学」）—— 该类别里有余量就抢
- **指定课**：在输入框打课名或课号，点「锁定」
- **必修**：切到「必修抢课」，输入**分组名**（比如「篮球」），点「锁定」

**第三步 · 开抢**

点「🚀 开始」，然后就可以走人了。
轮次出现自动进 → 课程一开放自动抢 → 抢到自动停。

## 面板按钮

| 按钮 | 作用 |
|---|---|
| 🛰 守候轮次 | 轮次还没放出来时，自动重查并等它出现 |
| 🎯 进入守候并抢课 | 现在就进轮次，课程一开放就抢 |
| 🚀 开始 / ⏹ 停止 | 手动开关 |
| 类别芯片 | 点亮 = 把这个类别加进队列 |

## 三件容易误会的事

- **池子里的课很少**（比如只有 10 门）通常正常 —— 那一轮只放开了部分课程（例如只放网课）
- **搜到课却不提交**：看那行「都不可抢：…」—— 满 / 时间冲突 / 已在课表，都不会抢
- **必修按分组名找，不按课程名**：一门体育课的十几个分组全叫「体育（3）」，要用「篮球」「健美操」这种分组名
